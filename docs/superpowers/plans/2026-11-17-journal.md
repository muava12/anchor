# Journal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Journal page (day timeline + calendar) for notes tagged `journal`, and a journal editor with a mood picker and a date pill.

**Architecture:** Journal entries are ordinary notes. A leading metadata block in the note content (`mood:` / `date:` / `time:` / `---`) carries the mood and the entry time. A content codec hides that block from the editor and writes it back on save. The Journal page is a new `NoteFolder` value rendered by a dedicated screen, reusing the existing drawer, search bar, and tokens.

**Tech Stack:** Flutter, Dart, Riverpod, drift, Quill, go_router, mocktail, flutter_test.

**Spec:** `docs/superpowers/specs/2026-11-17-journal-design.md`

## Global Constraints

- **Mobile only.** Never modify `server/`, `web/`, or `design/` for this feature. Stop if a change would need the server.
- Use the existing tokens and widgets (`AnchorTokens`, `AppTypography`, `NoteSurface`, `TagChip`, `EditorToolbar`, `NotesBottomBar`, `AppScaffold`, `Pressable`). No hardcoded palette.
- Theme follows the app theme (`context.anchor`, `context.isDark`). Never force the reference frame's dark colours.
- One locale: `lib/l10n/app_en.arb`. `flutter gen-l10n` does not rewrite the checked-in files, so hand-patch `lib/l10n/app_localizations.dart` and `lib/l10n/app_localizations_en.dart`.
- Do not change the drift schema, the sync payload, or the note model.
- Run every check from `mobile/` with `rflutter`: `cd mobile && rflutter test <path>` and, at the end, `cd mobile && rflutter analyze && rflutter test`.

## Review Focus

1. A note whose content is plain text, not ops JSON. `decodeNoteOps` wraps it; the header parser must still find a leading block or fall back cleanly.
2. A `---` line in the body but not in the leading block. It must not be read as metadata.
3. An empty body after `---`. Saving must not add stray blank ops, and the note must still save.
4. Local wall-clock dates. A 23:30 local entry groups on its local day, not the UTC day.
5. A renamed or deleted `journal` tag. The page empties and does not crash.

Each focus line gets a test in the task that owns the code: 1–3 in Task 1, 4 in Task 4, 5 in Task 7.

```dart

void main() {
  group('parseJournalContent', () {
    test('reads mood, date, time and the body', () {
      const content =
          '{"ops":[{"insert":"mood: good\\ndate: 2026-11-17\\ntime: 09:41\\n---\\nMorning pages\\n"}]}';
      final entry = parseJournalContent(content);
      expect(entry.meta.mood, JournalMood.good);
```

Add these cases to the same group:

- keys are case-insensitive and in any order (`Mood: Rough`, `TIME: 21:05`, `Date: 2026-01-02`).
- a plain text note with no `---` has an empty meta and the same body.
- a `---` line after body text is not metadata (`{"ops":[{"insert":"Hello\\n---\\nworld\\n"}]}` → `meta.isEmpty`).
- a header with `date` but no `time` has `entryAt == null`.
- unknown keys are kept in `meta.extras`.
- an empty body after `---` composes to one header op only.
- `composeJournalContent` then `parseJournalContent` round-trips a body with a bold op.

- [ ] **Step 2: Run the tests to verify they fail**

Run: `cd mobile && rflutter test test/journal_meta_test.dart`
Expected: FAIL. `journal_meta.dart` does not exist.

- [ ] **Step 3: Implement the codec**

Rules, in `journal_meta.dart`:

- `parseJournalContent`: `decodeNoteOps(content)`. If the first op is not `{'insert': String}`, return an empty meta and the original content.
- Split that first insert on `\n`. Find the first line whose `trim()` is `---`.
- If there is no `---`, or a line before it is not `key: value`, or no known key (`mood`, `date`, `time`) appears, return an empty meta and the original content.
- Parse `mood` with `journalMoodFromName` (case-insensitive). Parse `date` as `yyyy-MM-dd` and `time` as `HH:mm`; both must parse, or `entryAt` is null. Use local `DateTime`.
- Unknown keys go to `extras`. The body is the text after the `---` line (drop the header lines and the newline after `---`) plus every op after the first.
- `composeJournalContent`: if `meta.isEmpty`, return `body`. Otherwise build `mood:` / `date:` / `time:` lines, then extras, then a `---` line, as one `{'insert': header}` op, followed by `decodeNoteOps(body)`.
